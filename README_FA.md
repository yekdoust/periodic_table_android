# جدول تناوبی ۱۱۸ عنصر — نسخه اندروید

این پروژه نسخه اندرویدی فایل Python ارسالی `periodic_table_118_grouped_3d_no_overlap_tooltips.py` است. داده‌های عناصر و منطق آرایش الکترونی از همان فایل استخراج شده‌اند. رابط کاربری برای لمس موبایل بازطراحی شده است.

## امکانات
- نمایش ۱۱۸ عنصر با ساختار ۱۸ گروه و بلوک‌های لانتانید/اکتینید
- جست‌وجو با عدد اتمی، نماد، نام لاتین، نام فارسی و دسته
- نمایش عدد اتمی، عدد جرمی، نماد، نام‌ها، دسته، دوره و گروه
- آرایش الکترونی فشرده و کامل
- توزیع الکترون‌ها در لایه‌ها
- یون‌های رایج آموزشی موجود در فایل اصلی
- کنترل مجموع الکترون‌ها
- محاسبهٔ آموزشی گروه از روی آرایش الکترونی
- لمس هر خانه برای انتخاب عنصر

## ساخت APK بدون Android Studio
این پروژه برای GitHub Actions آماده شده است. پوشه را داخل یک مخزن GitHub قرار دهید و Workflow با نام `Build Android APK` را اجرا کنید. فایل APK در بخش **Artifacts** با نام `periodic-table-android-apk` قرار می‌گیرد.

از AGP 9.4.0 و Gradle 9.6.0 استفاده شده است؛ AGP 9.4 طبق مستندات رسمی با JDK 17، SDK 37 و Build Tools 36.0.0 سازگار است.

## تفاوت عمدی با نسخه دسکتاپ
در Android مفهوم Hover موس وجود ندارد؛ بنابراین Tooltipهای نسخه Tkinter با «لمس خانه» و نمایش اطلاعات در پنل جزئیات جایگزین شده‌اند.
